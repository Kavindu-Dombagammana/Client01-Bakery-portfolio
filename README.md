# Witch's Hut
A modern and elegant bakery portfolio website designed to showcase handcrafted baked goods, brand identity. This project focuses on creating a visually appealing and user-friendly platform where customers can explore products, learn about the bakery, and connect with the brand.

## 📌 About The Project

This bakery portfolio was created to represent the creativity, quality, and passion behind a professional bakery brand. The website highlights the bakery's story, products, team, and services through a clean and responsive design.

The goal of this project is to create an online presence that reflects the bakery's personality while providing visitors with an enjoyable browsing experience.

## ✨ Features

- 🏠 Beautiful homepage with bakery branding
- 🍰 Product showcase for cakes, pastries, and desserts
- 📖 About Us section with bakery story and values
- 👩‍🍳 Our Team section
- 🖼️ Image gallery for bakery creations
- 📞 Contact section for customer inquiries
- 🎨 Modern UI design focused on user experience

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🎯 Project Goals

- Create a professional online identity for a bakery
- Practice front-end web development skills
- Improve UI/UX design abilities
- Build a responsive website suitable for real-world use
